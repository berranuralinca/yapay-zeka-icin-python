## 🚀 Kurulum

Projeyi klonlayın:

```bash
git clone https://github.com/berranuralinca/yapay-zeka-icin-python.git
cd yapay-zeka-icin-python
```

Sanal ortam oluşturun:

```bash
python -m venv venv
```

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

Bağımlılıkları yükleyin:

```bash
pip install -r requirements.txt
```
